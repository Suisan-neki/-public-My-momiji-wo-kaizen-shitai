# 留年版終末時計（ブラウザ版）設計書

## 目的
- 毎日1回の手動更新で「留年までの残り日数（またはポイント）」を可視化する。  
- 0 になったら「留年」到達として強調表示する。  
- ブラウザだけで動作し、サーバーなしで運用できる（静的サイト想定）。

## 背景・前提
- ユーザーが毎日 1 回更新を行う。  
- 自分専用のシンプルな管理ツールとして使う。  
- 最低限の入力で継続できることを重視。

## 用語
- **残り値**: 留年までの残り日数／ポイントなど、減らしていく値。  
- **更新**: 1 日 1 回の手動操作で残り値を減らす操作。

## ゴール（機能要件）
1. **残り値の表示**  
   - 大きな数字で表示。  
   - 0 になったら視覚的に強調（赤、点滅、警告文など）。
2. **更新（デクリメント）操作**  
   - 「今日の更新」ボタンで 1 減らす。  
   - 1 日 1 回の更新を守れるように、当日更新済みならボタンを無効化する。
3. **初期設定**  
   - 初期値の入力（例: 100 日）。  
   - いつでも再設定できる「リセット」機能。
4. **状態の保存**  
   - ページを閉じても状態が保持される（ローカルストレージ）。
5. **更新履歴の最小記録（任意）**  
   - 最新更新日時だけを保存。詳細ログは不要。

## 非ゴール（やらないこと）
- ユーザー認証、複数ユーザー対応。  
- サーバー連携、クラウド同期。  
- 大規模な履歴分析やグラフ表示。

## 画面・UI（案）
- **ヘッダー**: 「留年版終末時計」タイトル。  
- **メイン表示**: 残り値（巨大な数字）。  
- **ステータス**: 「最終更新: YYYY-MM-DD」
- **操作ボタン**:  
  - 「今日の更新（-1）」  
  - 「リセット」  
- **警告エリア**: 0 到達時に「留年です」メッセージ。

## 状態管理設計
- LocalStorage に以下を保存:
  - `remaining`: number（残り値）
  - `lastUpdated`: string（ISO 日付: YYYY-MM-DD）

### 更新ロジック
1. ページ読み込み時に `remaining` と `lastUpdated` を取得。  
2. 今日の日付が `lastUpdated` と同じなら、更新ボタン無効化。  
3. 更新ボタン押下で `remaining - 1`、`lastUpdated = 今日` を保存。

### リセットロジック
- 初期値入力 → `remaining` に保存、`lastUpdated` を空にする（または今日の日付）。

## エラーハンドリング
- `remaining` が未設定なら初期設定画面を表示。  
- `remaining` が 0 未満にならないようガード。  
- 無効な入力（非数値・負数）にはエラーメッセージ。

## アクセシビリティ
- ボタンはキーボード操作可能。  
- 数値表示は十分なコントラストを確保。  
- 状態変化（0 到達）時に視覚以外の手がかり（テキスト）も付与。

## 技術スタック（想定）
- HTML / CSS / JavaScript（Vanilla）  
- 1 ページ構成（静的サイト）  
- LocalStorage を使用

## 今後の拡張アイデア（任意）
- 更新の連続日数（ストリーク）表示。  
- 背景色が残り値に応じて変化。  
- 残り値が 0 のときのアニメーション演出。

## 完了条件
- 毎日 1 回の更新が可能。  
- 残り値と更新日が保持される。  
- 0 到達時の警告が表示される。
